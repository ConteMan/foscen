# Foscen 品牌资产

主标是**方中方**：一个圆角方，正中挖掉一块方形空洞。外方是场景，内洞是焦点，表达 Focus + Scene，不借助任何字母。2026-08-25 重做，废止了旧的「聚焦框 + 场景方块 + F」三层结构与品牌绿。

| 文件                  | 用途                                                                  |
| --------------------- | --------------------------------------------------------------------- |
| `foscen-icon.svg`     | 应用图标源：底板 + 字形。只用于生成 `foscen.icns`                     |
| `foscen-mark.svg`     | 应用内 16 / 24 / 32px：只有字形，无底板                               |
| `foscen-wordmark.svg` | 文档与网站横向使用                                                    |
| `foscen.icns`         | 由 `./scripts/generate-icon.sh` 从 `foscen-icon.svg` 生成，不手工编辑 |

颜色：底板 `#16161A`，字形 `#F5F5F7`。中性板，无强调色。

比例：洞的边长是字形边长的 1/3；字形圆角 24%，洞圆角 27.5%。整体缩放，不单独调其中一项。

## 硬约束

- **界面里不要缩放 `foscen-icon.svg`。** 16px 时圆角底板吃掉外圈约 5px，字形只剩 6–7px 必然发糊。应用内一律用脱板的 `foscen-mark.svg`。
- 字形是「图」，洞是「地」。深底上字形为浅色，浅底上字形为深色，不要反过来让洞变成主体。
- 不要拉伸、旋转、改变洞与字形的比例，或在复杂背景上移除必要留白。

## 接入合同

- 可信控制面、内置落地页和关于页使用 SVG 资产，不用文字 `F` 代替正式标志。
- 打包应用统一使用产品名 `Foscen`、bundle id `com.conteman.foscen` 和 `foscen.icns`。
- 品牌资源只从随包本地路径加载，不引入远程图片或放宽 CSP（`img-src 'self'`）。
- `pnpm start` 启动的是 Electron 开发宿主，不作为 macOS 系统身份验收依据。
- Finder、Dock、菜单栏、窗口切换器与活动监视器必须使用打包后的 `Foscen.app` 验收。
