# Foscen 设计稿

Foscen 的视觉语言是**低干扰的中性深色容器**：网页是主角，可信 UI 只在被召唤时出现，出现时也只占它真正需要的面积。整套界面只有黑白灰，没有强调色——层级全部由明度承担。

## 三种职责，三个地方

| 职责                     | 事实源                                            | 生命周期                 |
| ------------------------ | ------------------------------------------------- | ------------------------ |
| 现状——应用现在长什么样   | `docs/design/current/*.png`（真机截图）           | 只增不改                 |
| 目标——这一版要变成什么样 | `design/foscen-ui.pen`                            | 版本内反复改，结版后冻结 |
| 标准——可实现的精确数值   | `docs/design/spec.md` + `docs/design/tokens.json` | 就地改，注明哪版引入     |

**设计稿不是数值的事实源。** 尺寸、颜色、字阶、动效以 `docs/design/tokens.json` 为准；设计稿负责表达形态与关系，两边不一致时以 tokens 为准并回头修稿。

## 这一版的判据

1. **⌘L 是「去某处」，⌘⇧P 是「做某事」。** 两者查询域不同，不能合成一个万能面板。
2. **面板只占它需要的高度。** 高度 = 10 + 44 + 行数 × 40 + 28 + 8，由建议行数决定，不预留最大值。
3. **错误紧挨输入。** 不把校验结果丢到远处的状态位。
4. **高亮是一条底，不是一张卡片。** 建议行不加阴影、不加边框、不做卡片化。
5. **没有强调色。** 面板只用中性墨阶 `#0A0A0B → #26262A`，文字与图标只用 `#F5F5F7 / #A1A1A6 / #6E6E73`。焦点环是 70% 白；错误不靠颜色，靠警示图标与加亮描边。品牌绿 `#72DBA5` 已于 2026-08-25 退出界面，只在画板 00 的现状复刻里保留。
6. **面板是不透明实色 `#1C1C1E`。** 2026-08-25 选定风格乙：覆盖层落在任意 HTTPS 网页上，实色是唯一在所有页面上表现一致的，也不需要 `prefers-reduced-transparency` 降级分支。
7. **品牌默认不出现。** 2026-08-27 标志定稿为「光圈」：倒圆角六边形 + 向上的三角光孔，轮廓不是圆角矩形。品牌红 `#D05954` 只用于 Dock 图标与 wordmark；**覆盖层与工作面一律没有品牌标、也没有品牌色**，应用内唯一的例外是关于页。容器应该消失，不该自我宣传。
8. **不扩展成通用浏览器。** 没有书签体系、浏览历史、搜索引擎、多标签。已保存场景就是 Foscen 的「地点」。

## 与 `docs/design/` 的关系

`docs/design/` 是设计论证与规范：现状评估、方向比较、可实现规范、token、可点选 HTML 原型、品牌探索图。
`design/` 是评审用的可视化稿。前者回答「为什么这样」，后者回答「长什么样」。

架构决策见 [ADR-0004](../docs/adr/0004-on-demand-omnibar.md)。
