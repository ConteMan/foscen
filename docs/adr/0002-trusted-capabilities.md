# ADR-0002：桌面能力采用可信控制面、默认拒绝和固定存储边界

- 状态：已接受
- 日期：2026-08-13

## 背景

截图、下载、场景、网页权限和应用升级都会跨越网页与桌面边界。网页内容不受信任，不能直接获得文件系统、IPC 或 Electron API；同时 Foscen 需要让这些能力可通过键盘使用。

## 决策

- scene View 不配置 preload，不能调用应用 IPC；所有桌面能力由本地 chrome View 的白名单 bridge 发起。
- 主进程逐项验证 IPC sender、主 frame、固定本地文档和参数；未知 channel 或输入默认拒绝。
- 下载必须来自 scene、具有用户手势且完整 URL 链均为无凭据 HTTPS；审批前暂停到私有暂存路径，完成后排他发布，不覆盖既有文件。
- 权限只支持明确白名单，绑定当前主 frame 的精确 HTTPS origin，并区分一次、会话和持久决定；设备与屏幕捕获保持拒绝。
- 场景与权限只写入 Electron 提供的 `userData`，业务 API 不接受文件路径；文件使用严格版本、限长读取、私有权限和原子替换。
- 自动升级只在已打包 macOS 应用中连接固定的 `ConteMan/foscen` 公共更新源，安装必须由可信 UI 明确触发。

## 后果

网页不能静默下载、截图、持久授权或改变升级源。代价是网页能力会比通用浏览器更克制，跨来源 iframe、未知媒体类型和未建模设备会被拒绝；正式升级必须维护稳定 bundle id、产品名和签名身份。

## 复审条件

新增权限类型、外部协议、屏幕捕获、可配置更新源或任意文件路径能力时必须复审本决策并新增安全测试。
