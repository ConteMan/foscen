# 覆盖层无障碍审计清单

对照 [WAI-ARIA 1.2 Combobox](https://www.w3.org/TR/wai-aria-1.2/#combobox)、[APG Combobox（Listbox Popup）](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) 与现有 `src/renderer/index.html` 的 tablist。实现阶段必须把下列断言做成可重复验证（单测能锁 DOM 合同的就锁；焦点与读屏走人工 + VoiceOver）。

画稿数值仍以 [omnibar.md](omnibar.md) 为准。文案以 [copy.md](copy.md) 为准。

## 0. 现有结构里要保留、不要倒退的

当前控制面已经有、新 UI 必须继续满足：

| ID  | 断言                                                                                                                                    | 现状出处                                       |
| --- | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| E1  | 图标按钮有中文 `aria-label`，可见字符（`←×↻`）`aria-hidden`                                                                             | `index.html` 24–31                             |
| E2  | 地址输入有关联 `<label class="visually-hidden">`                                                                                        | `index.html` 34–35                             |
| E3  | 动态结果用 `role="status"` + `aria-live="polite"`，不解释网页 HTML                                                                      | `index.html` 23；`index.ts` 动态 `textContent` |
| E4  | 工作面 tablist：`role="tablist"` / `tab` / `tabpanel`，选中 `aria-selected="true"`，`aria-controls` 指向面板 id，面板 `role="tabpanel"` | `index.html` 48–103                            |
| E5  | 未选中 tab `tabIndex=-1`，选中 `tabIndex=0`；左右箭头、Home、End 移动并激活                                                             | `index.ts` 109–123、418–441                    |
| E6  | tabpanel 可程序聚焦（`tabindex="-1"`）以便切 tab 后读屏落点                                                                             | `index.html` 101                               |
| E7  | `:focus-visible` 2px 实线，不得 `outline: none` 且无替代                                                                                | `styles.css` 69–73                             |
| E8  | 关闭按钮可被辅助功能找到，不只靠 `×` 字形                                                                                               | `aria-label="关闭"`（新文案，见 copy.md）      |

倒退即不合格：拿掉 label、把错误只放进无 live 的装饰、工作面 tab 变成无障碍无法切换的 div。

## 1. 地址条 / 命令面板：ARIA 1.2 combobox

模式：输入保持 DOM 焦点，弹出 `listbox`，用 `aria-activedescendant` 表示高亮。**不要**把焦点移进每一行。

覆盖层是对话框：

| ID  | 断言                                                                                                      |
| --- | --------------------------------------------------------------------------------------------------------- |
| C0  | 根节点 `role="dialog"`、`aria-modal="true"`。地址条 `aria-label="打开场景"`，命令面板 `aria-label="命令"` |
| C1  | 打开时焦点进入 combobox 输入，不得停在 `document.body` 或 dialog 自身                                     |
| C2  | 关闭后焦点回到 scene `webContents`，不得丢在已隐藏的 View                                                 |
| C3  | 打开期间 Tab 不把焦点送到关闭按钮（地址条/命令面板的 Tab 是补全，见 K5）。Esc 与关闭按钮是离开路径        |
| C4  | `aria-modal` 不得把评审工具条做成产品 DOM；产品构建里 dialog 外不应再有需交互的可信控件                   |

Combobox 本体：

| ID  | 断言                                                                                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C5  | 输入元素 `role="combobox"`（原生 `<input>` 也要显式写上，避免引擎推断不一致）                                                                                 |
| C6  | `aria-autocomplete="list"`                                                                                                                                    |
| C7  | `aria-haspopup="listbox"`                                                                                                                                     |
| C8  | `aria-expanded="true"` 在 overlay 可见且弹出层展示时（含空态文案、错误行、加载行）；overlay 隐藏后整个 View `hidden`，不依赖把 expanded 设 false 给已卸载焦点 |
| C9  | `aria-controls` 等于 listbox 的 `id`（建议 `omnibar-list` / `palette-list`）                                                                                  |
| C10 | `aria-activedescendant` 在有高亮 `option` 时等于该 option 的 `id`（`opt-0`…）；无 option 时为 `""` 或不设                                                     |
| C11 | 输入有可见或隐藏 label。地址条：`HTTPS 地址或场景`；命令面板：`搜索命令`（copy.md）                                                                           |
| C12 | placeholder 不得充当唯一 label                                                                                                                                |

Listbox：

| ID  | 断言                                                                                                                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------- |
| L1  | 列表容器 `role="listbox"`，`id` 与 C9 一致，`aria-label="建议"` 或 `命令`                                                       |
| L2  | 每一条可激活建议 `role="option"`，有稳定 `id`                                                                                   |
| L3  | 高亮项 `aria-selected="true"`，其余 `"false"`。同一时刻恰好 1 个 true（有 option 时）                                           |
| L4  | 错误行、空态说明、加载说明 **不是** `option`。错误/加载用 `role="status"` + `aria-live="polite"`，紧挨输入，不放在远离的 header |
| L5  | option 文本用 `textContent` 组装（标题 + 空格 + URL），不把场景名当 HTML                                                        |
| L6  | 图标 SVG `aria-hidden="true"`，不单独读成无意义图形                                                                             |
| L7  | 行数 0 时 listbox 可保留但无 option；空态文案在 status 节点，读屏能读到 copy.md 的空态句                                        |

键盘（相对 APG 的差异写进断言，避免实现「按 APG 默认做」）：

| ID  | 断言                                                                                            |
| --- | ----------------------------------------------------------------------------------------------- |
| K1  | `ArrowDown` / `ArrowUp`：`preventDefault`，循环高亮，焦点仍在输入，更新 C10 与 L3               |
| K2  | `Enter`：激活高亮 option；无 option 且输入可规范化则前往；非法则保持错误 status，不关闭         |
| K3  | `Escape`：关闭 overlay，焦点回 scene（比 APG「只关 popup」更强，这是产品要求）                  |
| K4  | `Home` / `End` 在输入内移动光标，不移动高亮（避免和 tablist 的 Home/End 混淆）                  |
| K5  | **有意偏离 APG**：`Tab` 把高亮项的 URL 或名称写入输入，不提交、不移焦。`Shift+Tab` 同样留在输入 |
| K6  | 关闭按钮可点可点按；键盘用户不依赖 Tab 到达它                                                   |
| K7  | `⌘L` 在已打开地址条时全选输入；在命令面板/工作面时切到地址条并全选                              |

## 2. 工作面：沿用并收紧 tablist

工作面 **不是** combobox。Tab 恢复标准焦点循环。

| ID  | 断言                                                                                                            |
| --- | --------------------------------------------------------------------------------------------------------------- |
| T1  | `role="tablist"` `aria-label="工作面分类"`，三项：场景、下载、设置                                              |
| T2  | 每个 tab `role="tab"` `aria-controls` 对应 `tabpanel` id：`panel-scenes` / `panel-downloads` / `panel-settings` |
| T3  | 仅选中 tab `aria-selected="true"` 且 `tabIndex=0`，其余 `-1`                                                    |
| T4  | 对应 tabpanel `role="tabpanel"` `tabindex="-1"`，未选中 `hidden`                                                |
| T5  | 左右箭头、Home、End 只在 tab 聚焦时切换，不与地址条抢键（此时地址条不在 DOM 或 `hidden`）                       |
| T6  | 打开工作面时焦点：场景→名称输入；下载→第一个「允许下载」或 panel；设置→第一个控件；`⌘U`→「检查升级」            |
| T7  | 工作面 Tab 顺序：关闭 → tablist → 面板内控件 →（循环）。不要把 Tab 做成补全                                     |
| T8  | 删除场景的 `confirm` 文案用 copy.md，读屏能读到场景名                                                           |
| T9  | 权限「允许一次 / 本次会话 / 始终允许 / 拒绝」保持按钮，有可区分的 accessible name                               |
| T10 | 计数徽章若只是装饰，`aria-hidden`；若表达「有待办」，tab 的 accessible name 必须包含数量（例如「下载 2」）      |

## 3. 三种 overlay 不得串台

| ID  | 断言                                                                                                                                    |
| --- | --------------------------------------------------------------------------------------------------------------------------------------- |
| M1  | `overlayMode=omnibar`：无 tablist                                                                                                       |
| M2  | `overlayMode=palette`：无前进/后退，无 tablist，有 combobox                                                                             |
| M3  | `overlayMode=surface`：无 combobox 地址建议，有 tablist                                                                                 |
| M4  | 同一时刻只有一个 dialog 可见                                                                                                            |
| M5  | View `setVisible(false)` 后，辅助功能树不应再把隐藏控制面当成可聚焦窗（若 Electron 仍暴露，文档化为已知限制，键盘焦点必须已回到 scene） |
