# 品牌标

2026-08-27 定稿。第三版，前两版都废止了：

- 「聚焦框 + 场景方块 + F」——三层结构，16px 下 F 必然消失。
- 「方中方」——圆角矩形 + 圆角矩形，通过了可辨认性测试但通不过归属性测试：换个产品名照样成立。

现在的标是**光圈**：一个倒圆角的六边形，正中一个向上的三角光孔。选它的理由在 [brand-research.md](brand-research.md) 里有完整推导，简述如下。

## 为什么是这个形

GNOME 的图标指南要求轮廓自身要独特，并明确警告不要「把几何形贴在圆角矩形上」。六边形是这轮探索里唯一真正跳出圆角矩形的轮廓——**涂成纯黑剪影仍然认得出**，这是前两版都没做到的。

三角光孔取自 `Foscen` 名字里的 focus（光圈 / 对焦）。名字 → 物 → 形的链条是完整的。

探索过程中被否掉的：拱窗是墓碑，胶片格的侧齿读作芯片引脚，抽帧的剪影是两团糊在一起，光锥是灯罩，内外同向的六边形是螺母。顶点倒圆角之后螺母感消失，是这一族里唯一活下来的。

## 品牌色只属于品牌

品牌红 `#D05954`，2026-08-27 采用。

标是纯黑白灰的时候，识别度全压在一个几何形上，负担过重——参照 Zed 的 Z、Vercel 的三角形，它们不显得廉价是因为识别度由「标 + 色 + 字标 + 一致应用」四根柱子共同承担，而我们把色这根拆掉了。品牌色补回其中一根。

分界是刻意的：

| 语境                                | 配色       | 理由                         |
| ----------------------------------- | ---------- | ---------------------------- |
| Dock / Finder / 关于页              | 品牌红     | 任务是被认出来               |
| 覆盖层 / 工作面 / 地址条 / 命令面板 | 纯中性墨阶 | 任务是退让，压在别人的网页上 |

**覆盖层不得出现品牌红。** 无强调色、层级只靠明度这条不变，见 `tokens.json` 的 `brandAccent.forbidden`。

## 两份资产，不是一份

小尺寸难分辨的根因是底板不是形状。16px 一共 16 像素宽，圆角底板吃掉外圈约 5px，标只剩 6–7px。所以拆开：

| 文件                               | 用途                          | 构成                 |
| ---------------------------------- | ----------------------------- | -------------------- |
| `assets/brand/foscen-icon.svg`     | Dock / Finder / `foscen.icns` | 红底 + 浅色标        |
| `assets/brand/foscen-mark.svg`     | 应用内                        | 只有标，满幅，纯中性 |
| `assets/brand/foscen-wordmark.svg` | 浅底文档与网站                | 红标 + Foscen 字标   |

几何比例与硬约束见 [assets/brand/README.md](../../assets/brand/README.md)。

## 用法：默认是「不放」

品牌只出现在需要被认出来的地方。**容器应该消失，不该在自己的界面里做自我宣传。**

| 表面                   | 用法                                         |
| ---------------------- | -------------------------------------------- |
| Dock / Finder / 菜单栏 | `foscen.icns`                                |
| 关于                   | `foscen-mark.svg` 48px + Foscen + 版本 + MIT |
| 落地页                 | 现有大号字标，不改                           |
| 地址条 / 命令面板      | **不放品牌**                                 |
| 工作面标题             | **不放品牌**，只有文字标题                   |
| 空态                   | **不放品牌**，只有文案                       |

地址条的工具图标（后退 / 前进 / 刷新 / 关闭）不是品牌标，用 lucide 描边 1.75，与品牌资产无关。

## 16px 实测

用 `qlmanage -t -s N` 从 SVG 实渲，再按邻近插值放大看像素，不是目测推断。

| 尺寸      | `foscen-icon.svg`（带板） | `foscen-mark.svg`（脱板） |
| --------- | ------------------------- | ------------------------- |
| 16px      | 结构可辨，三角孔糊成一点  | 六边形与三角都清楚        |
| 24px      | 可读                      | 清晰                      |
| 32px 以上 | 清晰                      | 清晰                      |
