# 品牌标

2026-08-25 重做。旧标是「聚焦框 + 场景方块 + F」三层结构，被判定为在小尺寸下难以分辨且过于繁琐，连同品牌绿一起废止。

新标是**方中方**：一个圆角方，正中挖掉一块方形空洞。外方是场景，内洞是焦点——Focus + Scene 不借助任何字母。

- 结构：一个形 + 一个洞。没有边框、没有内层底、没有字母。
- 配色：底板 `#16161A`，字形 `#F5F5F7`。中性板，无强调色。
- 比例：洞的边长是字形边长的 1/3；字形圆角 24%，洞圆角 27.5%。三者按比例缩放，不单独调。

## 两份资产，不是一份

小尺寸难分辨的根因是底板，不是形状。16px 一共 16 个像素宽，圆角底板吃掉外圈约 5px，留给字形只剩中间 6–7px——画什么都会糊。所以拆成两份：

| 文件                               | 用途                          | 构成                       |
| ---------------------------------- | ----------------------------- | -------------------------- |
| `assets/brand/foscen-icon.svg`     | Dock / Finder / `foscen.icns` | 底板 + 字形，字形占 47%    |
| `assets/brand/foscen-mark.svg`     | 应用内 16 / 24 / 32px         | 只有字形，吃满整格，无底板 |
| `assets/brand/foscen-wordmark.svg` | 文档与网站横向                | 字形（深色）+ Foscen 字标  |

`foscen.icns` 由 `./scripts/generate-icon.sh` 从 `foscen-icon.svg` 生成，不手工编辑。

## 16px 实测

用 `qlmanage -t -s N` 从 SVG 实渲，再按邻近插值放大看像素，不是目测推断。

| 尺寸      | 带板（`foscen-icon.svg`）        | 脱板（`foscen-mark.svg`） |
| --------- | -------------------------------- | ------------------------- |
| 16px      | 结构可辨但整体发糊，洞只剩 1–2px | 干净可读，洞约 4.6px      |
| 24px      | 可读                             | 清晰                      |
| 32px 以上 | 清晰                             | 清晰                      |

结论：**应用内一律用 `foscen-mark.svg`，不要缩放带板图标。** 旧方案里那个「16px 专用简化变体」不再需要——脱板本身就解决了这一档。

## 废止记录

- 旧结构「聚焦框 + 场景方块 + F」：三层，16px 下 F 必然消失，需要额外维护一枚简化变体。
- 中间一版中性化尝试把图底关系反了（深灰方块 + 浅色 F），16px 实测方块并入底色只剩四角，已废弃。
- 品牌绿 `#72DBA5` 与相关 hex：记在 `tokens.json` 的 `deprecatedColor`。
- `explorations/brand-scale/` 下的旧栅格图对应的是废止的绿版与带框结构，只作历史，不再是现行依据。

## 各表面用法

| 表面              | 用法                                                         |
| ----------------- | ------------------------------------------------------------ |
| 地址条 / 命令面板 | 不放品牌                                                     |
| 工作面标题        | 24px `foscen-mark.svg` + 标题 15/600                         |
| 关于              | 24px `foscen-mark.svg` + Foscen + Focus + Scene + 版本 + MIT |
| 空态              | 可选 48px `foscen-mark.svg`，文案 12/400                     |
| 落地页            | 维持现有大号字标，不改                                       |
| Dock / Finder     | `foscen.icns`                                                |

## 实现要点

- `foscen-mark.svg` 需要进 `scripts/copy-static.mjs` 的拷贝清单，才能被可信 UI 以 `img-src 'self'` 加载。
- 资产里写死 `fill="#F5F5F7"`。若实现改为内联 SVG 而不是 `<img>`，可把 `fill` 换成 `currentColor` 以跟随文字色。
- CSP 维持 `img-src 'self'`，不引入远程图片。
- 地址条的 16px 工具图标（后退/前进/刷新/关闭）不是品牌标，用 lucide 描边 1.75，与品牌资产无关。
