## 方向 A — 极简聚焦条

**主张：** `⌘L` 只负责「打开或切换一个 HTTPS 场景」。桌面动作走 `⌘⇧P`。表单与审批走独立工作面。scene 网页始终是主界面。

### 适用理由

- README 把 Foscen 定义为聚焦、低干扰、键盘优先的场景容器，不是浏览器。
- 实地评估里 `⌘L` 真正被用到的只有地址框，其余都是遮挡。
- 已保存场景已经是「地点」数据，不必为了好用而做历史/书签。
- 下载审批和权限决定需要明确按钮，不该塞进地址建议。

### 代价

- 用户要记住两套瞬时层（去某处 / 做某事）再加工作面。
- control View 高度随建议行数变化，需要窄 IPC `reportOverlaySize`。
- ADR-0003 写的「命令」一级 tab 被取消，改为 palette。

### 对 ADR-0003 的影响

| ADR-0003 条款                      | 方向 A                                                         |
| ---------------------------------- | -------------------------------------------------------------- |
| 不覆盖 scene 的常驻命中区          | 遵守。View 紧贴面板                                            |
| 控制面顶部 drag、控件 no-drag      | 遵守。地址条顶部 10px drag                                     |
| 设置留在同一控制面、不新窗口       | 遵守。`⌘,` / `⌘U` 打开工作面                                   |
| 一级分类「命令、场景、下载、设置」 | **修订**：命令改为 `⌘⇧P` palette；工作面一级为场景、下载、设置 |
| 品牌用随包 SVG                     | 遵守。地址条不常驻 wordmark，工作面标题 24px icon              |

### 入口

| 入口  | 打开                               | 查询域                             |
| ----- | ---------------------------------- | ---------------------------------- |
| `⌘L`  | 地址条                             | 当前 URL、已存场景、可规范化 HTTPS |
| `⌘⇧P` | 命令面板（同一视觉壳，无前进后退） | 截图、保存场景、打开工作面分区     |
| `⌘S`  | 工作面 / 场景                      | 命名、打开、删除                   |
| `⌘J`  | 工作面 / 下载                      | 审批、进度                         |
| `⌘,`  | 工作面 / 设置                      | 窗口、权限、关于                   |
| `⌘U`  | 工作面 / 设置·更新                 | 升级                               |
| `⌘⇧S` | 无面板                             | 截图                               |
| `Esc` | 关闭                               | 焦点回 scene                       |

### 布局（逻辑像素）

地址条 / 命令面板：

```text
width  = min(640, windowWidth - 48)
x      = floor((windowWidth - width) / 2)
y      = clamp(round(windowHeight * 0.14), 72, 140)
height = 10 + 44 + rowCount * 40 + 28 + 8
         上限 min(360, windowHeight - y - 16)
rowCount 显示 0–6；超过 6 行在列表内滚动
```

工作面：

```text
width  = min(720, windowWidth - 48)
height = min(420, windowHeight - y - 16)
x      = floor((windowWidth - width) / 2)
y      = clamp(round(windowHeight * 0.10), 56, 96)
```

1280×800 对照：

|              | 现状           | A 地址条（4 行建议） | A 工作面       |
| ------------ | -------------- | -------------------- | -------------- |
| bounds       | 52,44 1176×530 | 320,112 640×250      | 280,80 720×420 |
| 约占窗口面积 | 61%            | 16%                  | 30%            |

窗口 < 520 宽：`width = max(1, windowWidth - 24)`，隐藏前进/后退。窗口 < 400 高：`y = 24`，最多 4 行。

阴影不得把 View 扩大。面板 `box-shadow` 画在内侧 1px 高光 + 外侧阴影被 View 裁切可接受。body 的 8px padding 取消，改由 View bounds 自己留出与窗口边缘的间隙。

### 地址条结构

```
[ 10px drag ]
[ 28×28 后退 ][ 前进 ][ 刷新 ][ 输入 36h ][ 28×28 关闭 ]
[ 建议行 × N，行高 40，左右 padding 12 ]
[ 页脚 28h：Esc 关闭 · ⌘⇧P 命令 · 仅 HTTPS ]
```

无「前往」按钮。无品牌字标。无 tab。

建议行类型与优先级：

1. 错误（显式 http / 凭据 / 其它协议）——独占，输入框 1px `#FFB5AC` 描边 + 3px `rgb(255 117 104 / 16%)` 外光。
2. 前往（`normalizeSceneUrl` 成功且不等于当前 URL）。
3. 当前（空查询，或输入等于当前规范化 URL）。
4. 场景（名称或 URL 子串，大小写不敏感，`updatedAt` 降序，最多 6，排除与当前 URL 相同的项）。

空查询以及「输入仍等于当前 URL」都按空态，不出现「前往」以免回车刷新。

### 状态（地址条）

| 状态     | 输入                                   | 列表                                                             | 焦点                            |
| -------- | -------------------------------------- | ---------------------------------------------------------------- | ------------------------------- |
| 空态     | 当前 URL，全选                         | 当前 + 最近场景                                                  | 输入框                          |
| 输入中   | 任意                                   | 即时过滤，高亮第 1 项                                            | 输入框                          |
| 有建议   | 合法或匹配场景                         | combobox + listbox                                               | 输入框，`aria-activedescendant` |
| 无结果   | 不能规范化且无场景匹配（如 `foo bar`） | 一行 12px `#9BB5A8`：「没有匹配的场景。补全 HTTPS 地址后回车。」 | 输入框                          |
| 非法输入 | 显式非 HTTPS                           | 错误行，主进程原文案                                             | 输入框                          |
| 加载中   | 只读                                   | 一行「正在打开…」，刷新位换 14px spinner                         | 面板内                          |
| 失败     | 可编辑，危险描边                       | 「页面加载失败，请检查网络或地址」                               | 输入框                          |

成功：`hideChrome()`，焦点回 scene。

### 键盘

焦点留在输入框（ARIA 1.2 combobox）。

| 键         | 行为                                                            |
| ---------- | --------------------------------------------------------------- |
| `⌘L`       | 打开地址条；已在则全选；在其它覆盖层则切换到地址条              |
| `⌘⇧P`      | 打开命令面板                                                    |
| `↓` `↑`    | 移动高亮，循环，`preventDefault`                                |
| `Enter`    | 激活高亮；无高亮且可规范化则前往；非法则保持错误                |
| `Tab`      | 把高亮项 URL/名称填进输入，不提交                               |
| `Esc`      | 关闭，scene focus                                               |
| 点击 scene | 主进程 `hideChrome()`（监听 scene mousedown/focus，不用全窗垫） |

### 视觉（A 专用差异）

共用 token 见 [tokens.json](tokens.json)。A 的面板圆角 **12px**，控件 **8px**，建议行 **0 圆角 + 8px 高亮底** `rgb(114 219 165 / 14%)`。打开 120ms `cubic-bezier(0.2, 0.8, 0.2, 1)` 透明度 + 4px 下移；关闭 80ms 仅透明度。

## 方向 B — 统一 palette

**主张：** 用户只学习一个浮动对象。六个快捷键打开**同一个壳**，用 mode 切换查询域和高度。形态在「一行输入」和「展开工作面」之间连续伸缩。

### 适用理由

- 减少「我该按哪个」的记忆负担。
- `⌘L` 打字、`⌘⇧P` 打字、`⌘S` 打字可以是同一个输入框的三种解释。
- 与 VS Code / Raycast 的心智接近，键盘用户迁移成本低。

### 代价

- 输入框语义不稳定：同一控件有时是 URL，有时是命令，有时是场景名。必须用 11px 模式标签（「场景」「命令」）写在输入框左侧，占 52px 宽。
- 下载审批、权限四个按钮仍要把壳撑到工作面高度，统一是假象——mode 一变，尺寸跳变。
- 更容易滑向「搜万物启动器」，违反非目标。
- 实现上要在一次按键内重排 View bounds，更容易出现透明命中区。

### 对 ADR-0003 的影响

设置仍在同一控制面。一级分类变成 palette 的 mode 而不是 tab，比 A 更偏离 ADR-0003 的「分类」措辞。窗口外壳条款仍遵守。

### 入口（同一壳）

| 入口  | 初始 mode         | 初始高度公式                                           |
| ----- | ----------------- | ------------------------------------------------------ |
| `⌘L`  | `go`              | 与 A 地址条相同，输入 placeholder「打开场景」          |
| `⌘⇧P` | `command`         | 同上，placeholder「执行命令」                          |
| `⌘S`  | `scenes`          | 工作面高度，输入是场景名                               |
| `⌘J`  | `downloads`       | 工作面高度，输入过滤文件名（可选，首期可无输入只列表） |
| `⌘,`  | `settings`        | 工作面高度                                             |
| `⌘U`  | `settings/update` | 工作面高度                                             |

壳顶部恒为：`[10px drag][52px 模式标签][输入][关闭]`。`⌘L` 在已打开的壳里只切换到 `go` 并全选，不关再开。

模式标签是 11px/600、颜色 `#72DBA5`，点击或 `⌘[` `⌘]` 循环 mode（可选，首期可用 `⌘L/⌘⇧P/⌘S` 切换）。

### 布局

窄态（go / command）：同 A，宽 **600**（比 A 窄 40，因为左侧多了模式标签）。

```text
width = min(600, windowWidth - 48)
```

宽态（scenes / downloads / settings）：

```text
width  = min(680, windowWidth - 48)
height = min(400, windowHeight - y - 16)
y      = clamp(round(windowHeight * 0.10), 56, 96)
```

从窄到宽的动画 160ms 高度 + 宽度，`prefers-reduced-motion` 时瞬时切换。主进程必须在动画前就把 View 设到**目标较大矩形**，否则动画过程点到网页会穿。这是 B 独有的风险：短时间内 View 大于可视面板。缓解：View 立即跳到最大，面板 CSS 再 animate；透明差额用面板同色实底填满，**禁止透明**。

### 状态

go mode 的建议规则与 A 相同。command mode 过滤固定动作列表。scenes mode 输入提交 = 保存当前场景（不是导航）。

错误、加载、失败都显示在输入框下方第一行，不进远离的 header。

空态 go：当前 + 最近场景。空态 command：完整动作列表（6 项）。空态 scenes：保存表单 + 列表。

### 键盘

与 A 相同的 combobox 模型，外加：

| 键                     | 行为                                     |
| ---------------------- | ---------------------------------------- |
| `⌘L` 在 command/scenes | 切到 go，不关闭                          |
| `⌘⇧P` 在 go            | 切到 command，保留已输入字符串并重新过滤 |
| `Tab`                  | 补全当前行                               |
| `Esc`                  | 关闭整个壳                               |

### 视觉

圆角 **14px**（比 A 略更「卡片」）。模式标签与输入之间 1px `#72DBA5` 22% 竖线。列表行高 **38px**（比 A 密 2px），因为命令和场景混排需要更高密度。

## 方向 C — 保留重型面板，重构密度

**主张：** Foscen 的控制面是一个**命令台**，不是 Spotlight。多 tab 有价值，因为场景、下载、权限是持久工作，不是一行查询。错在层级和尺寸，不在「一块板」。

### 适用理由

- 下载审批、权限队列、场景管理本来就要并排对照。
- ADR-0003 原文就是「一级分类」，C 几乎原样落地。
- 对偶尔用鼠标的人，tab 比记住三套快捷键友好。
- 若用户把 Foscen 当「一个长期开着的场景工作台」，命令台比每次弹出条更稳。

### 代价

- 即使重构，面板仍明显大于 A/B，scene 被盖住的面积更大（1280×800 下约 720×400 = 28%，好于现状 61%，差于 A 的 16%）。
- `⌘L` 仍会看到 tab 和其它分区，任务焦点弱。
- 容易把「再加一个 tab」当成默认扩展方式。
- 不符合「按需浮现、用完即走」的键盘习惯。

### 对 ADR-0003 的影响

**最吻合。** 一级分类直接做成「命令 | 场景 | 下载 | 设置」。权限、升级迁入设置。品牌 SVG 放在 header 左侧 24px。

### 入口

六个快捷键仍打开**同一块重构后的面板**，切 tab / 焦点，和现在一样。区别是尺寸、密度、地址建议。

### 布局

```text
width  = min(800, windowWidth - 48)
height = min(400, windowHeight - y - 16)
x      = floor((windowWidth - width) / 2)
y      = 56
```

1280×800：240,56 800×400。720×540：24,56 672×400（受高限制）。

固定结构，高度不随建议行变化（建议列表最多 4 行，超出滚动）。View 尺寸固定，实现最简单，无动态高度 IPC。这是 C 相对 A/B 的工程优势。

### 结构

```
[ 44px header：24px icon + 「Foscen」15/600 + 弹性空白(drag) + 12px 状态 + 28 关闭 ]
[ 40px 导航：28 后退/前进/刷新 + 输入 36h + 无前往按钮 ]
[ 建议列表 0–4 行 × 36h，仅当焦点在地址框且（在输入或空态）时出现 ]
[ 36px tab：命令 / 场景 / 下载 / 设置，12/500，选中 13/600 + 2px 底线 #72DBA5 ]
[ 弹性内容，padding 16，不要 eyebrow，h1 改为 15/600 一行 ]
[ 28px footer ]
```

地址建议只在地址框聚焦时出现，不挤压 tab。命令 tab 改为单列 40h 行，不再 3×2 大按钮。场景列表行高 44，不再 52。

### 状态

地址相关状态发生在「导航行 + 建议」局部，不写进 header 状态——header 状态只保留操作结果（保存成功、截图路径）3 秒后淡出。

非法 HTTP：输入描边 + 建议区错误行。加载中：导航行右侧 14px spinner。成功导航仍 `hideChrome()`。

空场景：「还没有保存场景。」12/400 居中，不再被巨大空白放大。

### 键盘

地址聚焦时 ↑↓ 操作建议，Enter 前往。焦点在 tab 上时左右切换 tab（保留现状）。`⌘L` 打开面板并聚焦地址全选。`Esc` 关闭。

Tab 键：地址 → 建议（若有）→ tablist → 内容 → 关闭，循环。这是 C 与 A 的关键差异：A 的 Tab 是补全，C 的 Tab 是焦点移动。

### 视觉

圆角 **10px**（更「工具」）。header 与导航之间 1px `rgb(114 219 165 / 18%)`。去掉径向光斑。背景实色 `#10261C` + 可选 blur。阴影 `0 12px 32px rgb(0 8 5 / 32%)`，比现状轻一半以上。

## 推荐：A

1. 实地问题的核心是遮挡，不是缺 tab。A 直接砍掉遮挡。
2. README 非目标排除完整历史/书签/多标签；B 的「一个输入框搜所有」会持续吸引这些能力。
3. C 改善密度但仍让 `⌘L` 打开命令台，和「去某处」的快捷键惯例冲突。
4. A 对 ADR-0003 的修订范围最小且理由清楚：命令不是表单，不该占工作面 tab。
5. 动态高度 IPC 有成本，但比 B 的「先放大 View 再动画」安全。

若用户明早强烈希望「只记一个壳」，再改选 B。若希望设置/下载始终能看见 tab，选 C。默认按 A 写 [spec.md](spec.md) 和 tokens。

## 三方向共同硬约束

- 不新增 WebContentsView，不用全窗透明层。
- `contextIsolation` / `sandbox` / CSP / HTTPS-only / IPC 白名单不放宽。
- 不向 scene 注入 `app-region`。
- 建议数据：当前 URL + 已存场景（A/B 的 go mode，C 的地址聚焦）。不做搜索引擎、浏览历史、书签仓库。
- 品牌用随包 `foscen-icon.svg`，不用字母 `F`。
- 今晚不改 `src/`。
