三个方向的可点选原型（已归档）

简报 #3 已采纳方向 A，「三个产品方向」撤销；本目录仅作归档。现行原型见 omnibar-prototype.html（全状态）与 style-compare.html（甲 / 乙 / 丙 视觉变体）。 配色已于 2026-08-25 随全局改为中性黑白灰。

用浏览器直接打开。顶部芯片是评审工具，不是产品 UI。

  1. 方向 A · 极简聚焦条（推荐）
    ⌘L 只打开 640 宽地址条；命令走 ⌘⇧P；工作面另开。
  2. 方向 B · 统一 palette
    一个壳，左侧模式标签，go / command / scenes 切换并改变高度。
  3. 方向 C · 重构命令台
    800×400 多 tab，地址建议贴在输入下，去掉 eyebrow 大海报。
