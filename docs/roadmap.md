# 路线图

路线图描述能力顺序，不替代 Issue/PR 的任务状态。

## 0.1 工程切片

- 可运行的 BaseWindow + 双 WebContentsView；
- HTTPS 导航与基础键盘控制；
- 安全默认值、策略单测、Electron 启动 smoke；
- 文档、CI 和贡献控制面。

## 0.2 首个可用预览

- 导航状态与更完整的命令面板；
- 场景保存、命名、恢复与窗口状态；
- 无边框网页截图与明确的输出路径策略；
- 下载审批、进度、大小限制和文件冲突处理；
- 按 origin 的最小权限提示与持久策略；
- macOS universal 打包、签名、公证、可重复发布与自动升级基础设施。

## 下一阶段

- 使用 Developer ID 凭据完成 Intel 与 Apple Silicon 安装验收；
- 以两个递增签名版本验证 GitHub Release 跨版本升级；
- 评估下载取消/恢复和更明确的截图完成反馈；
- 根据真实使用反馈收敛场景管理与沉浸布局。

## 后续候选

- 多场景快速切换；
- 更丰富的沉浸模式与窗口布局；
- 在安全合同内评估其他桌面平台。

## 明确排除

Chrome 扩展生态、密码管理器、浏览器同步、多用户 Profile、完整书签/历史系统不在首期范围。
