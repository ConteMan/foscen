# 路线图

路线图描述能力顺序，不替代 Issue/PR 的任务状态。

## 0.1 工程切片

- 可运行的 BaseWindow + 双 WebContentsView；
- HTTPS 导航与基础键盘控制；
- 安全默认值、策略单测、Electron 启动 smoke；
- 文档、CI 和贡献控制面。

## MVP

- 导航状态与更完整的命令面板；
- 场景保存、命名、恢复和最近使用；
- 无边框网页截图与明确的输出路径策略；
- 下载进度、取消和文件冲突处理；
- 按 origin 的最小权限提示与持久策略；
- macOS 打包、签名、公证和可重复发布。

## 后续候选

- 多场景快速切换；
- 更丰富的沉浸模式与窗口布局；
- 在安全合同内评估其他桌面平台。

## 明确排除

Chrome 扩展生态、密码管理器、浏览器同步、多用户 Profile、完整书签/历史系统不在首期范围。
